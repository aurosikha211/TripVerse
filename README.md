# TripVerse 🌍

A modern travel discovery and trip-planning web application built with React and Vite.

## Features

- Explore travel destinations
- Search and filter destinations
- View destination details
- Responsive travel-focused interface

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- React Router
- Lucide React

## Getting Started

1. Clone this repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open the local URL displayed in your terminal.

Milestone 1: Frontend foundation and destination discovery UI.
